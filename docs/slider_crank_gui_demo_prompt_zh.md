# 曲柄滑块 GUI 文字建模提示词

在 FreeCAD 的 KineSketch 面板中，将 Endpoint 设为 `http://127.0.0.1:11434/v1`，Agent 设为 `modelscope.cn/unsloth/Qwen3.6-35B-A3B-GGUF:Q4_K_M`，勾选 SSH key tunnel，并确认服务器、端口和用户名分别是 `61.172.235.130`、`6010`、`asus_gx10`。此配置访问远端 Ollama 模型；在当前测试环境中无需 Access token。用仓库根目录的 `start_freecad.ps1` 启动 GUI，确保 FreeCAD 使用 Pixi 环境中的 DLL。

将以下文字完整粘贴到 KineSketch 输入框并点击 Send。这份文字在 FreeCAD 1.2.0 GUI 中实测通过，不要求模型调用固定的 `create_slider_crank_demo`。模型会提交新的盒体和圆柱体特征方案；几何、装配、运动三个 skill 按方案创建和验证文件。

```text
请仅根据下面的文字要求，在当前 FreeCAD GUI 中从零创建、装配并仿真一套双导轨曲柄滑块机构。不要打开已有零件文件，也不要使用固定样例几何。

曲柄两转轴中心距 32 mm，连杆两端中心距 126 mm，滑块与曲柄轴线零偏置。底板约 250 × 48 × 6 mm；沿 X 方向有两条长约 230 mm、宽 4 mm、高 9 mm 的平行导轨。滑块约 22 × 18 × 9 mm，应在两导轨之间留有侧向间隙。左端有固定转轴；曲柄和连杆是扁平杆，两端有圆形凸台。请根据这些要求规划四个独立零件各自的盒体、圆柱体尺寸和局部坐标，确保每个零件是一个连通实体、铰接点处有实体材料。

先生成四个实际的 FreeCAD 3D 零件，再用原生 Assembly 固定底座并建立转动副及导轨移动副，初始曲柄角 30°。用原生求解器验证装配后，以 60 rpm 仿真 2 圈，导出运动 CSV 和 FreeCAD 视口 MP4，并在 GUI 中循环播放 120 秒。最后报告实际采用的几何特征方案文件，以及零件、装配、仿真、CSV、MP4 的路径和各阶段验证结果。任何阶段失败都要说明错误，不要宣称已完成。
```

需要再次录制 GUI 回放时，发送：

```text
请在 FreeCAD GUI 中把刚才验证通过的曲柄滑块运动再播放 120 秒。
```

每次成功运行都在 `outputs/agent_slider_crank_<id>/` 下保留 `parts/design_plan.json`、四个 `.FCStd` 零件、装配、仿真、CSV、校验报告和 MP4。MP4 是 120 帧、30 fps、4 秒的 FreeCAD 视口导出；GUI 中的 120 秒是循环回放。当前流程支持这种零偏置曲柄滑块拓扑，尚不能仅凭任意机构描述或图片自动构造通用装配和运动副。
